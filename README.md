# Interactive Stock Market Dashboard (2018–2023)

This Streamlit application extends the Jupyter Notebook `Stock_Market_Data_Analysis.ipynb` and compares AAPL, MSFT, GOOGL, AMZN and NVDA.

## Run locally

1. Install Python 3.10+.
2. Unzip this folder and open a terminal inside it.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python -m streamlit run app.py`.
5. Open the local URL displayed in your terminal (typically `http://localhost:8501`).

Upload the `raw_stock_data.csv` generated by your Jupyter Notebook using the sidebar. If no CSV is uploaded, the app attempts to download 2018–2023 prices using `yfinance` (internet connection required).

## Features

- Select one or more stock tickers and a date range
- Dynamic cumulative-return and annualized-risk KPIs
- Closing and normalized price charts
- Annual and daily return charts
- Daily-return histogram and return correlation heatmap
- Risk versus return scatter plot
- Interactive data table and CSV export

## Calculation notes

Calculations follow the notebook: `Close` is used rather than `Adj Close`; daily returns are percentage changes, annualized mean return is daily mean × 252, and annualized volatility is daily standard deviation × sqrt(252). Calendar-year returns use the first and last observed close within each year. Changing the date filter resets the base for cumulative and normalized returns.
